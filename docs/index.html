PowerShell module for Microsoft Intune

Ship Win32 apps to Intune with one command.

Point Win32Forge at an app folder. It builds the .intunewin package, adds the Intune metadata and detection rules, and uploads it through Microsoft Graph.

Quickstart See examples
  • PowerShell 7+
  • Windows, macOS, Linux
  • PowerShell Gallery

Overview

What it handles

The packaging and Graph upload work between your source folder and a Win32 app in Intune.

  1. Prepare the folder

    Keep the payload, install and uninstall scripts, detection script, and icon together.

  2. Build the package

    Win32Forge creates the encrypted .intunewin file Intune expects.

  3. Add the metadata

    Name, publisher, version, install and uninstall commands, return codes, and detection rules.

  4. Publish to Intune

    Uploads and commits the content through Microsoft Graph, so the app appears as a Win32 app.

Setup

Install and prepare

You need PowerShell 7, two helper modules, an Intune tenant, and permission to create Win32 apps.

1. Install Win32Forge

Install-Module Win32Forge -Scope CurrentUser
Import-Module Win32Forge

2. Install helper modules

Install-Module Microsoft.Graph.Authentication, SvRooij.ContentPrep.Cmdlet -Scope CurrentUser

3. Lay out the app folder

  • install.ps1Install command script
  • uninstall.ps1Uninstall command script
  • detection.ps1Default detection script
  • icon.pngCompany Portal icon (PNG or JPG)
  • …Your application payload

Permissions and roles

Graph consent gets the token. Intune RBAC decides whether the signed-in admin can manage apps. You need both.

Tenant
An active Microsoft Intune license.
Graph
DeviceManagementApps.ReadWrite.All, delegated or application, with admin consent.
Delegated user
Application Manager, Intune Administrator, or a custom role with Mobile apps create, read, and update.
Replace mode
Add Mobile apps delete when you use -Force.
App-only
The application permission with admin consent.

Publish

Run the publish command

Use -WhatIf for a dry run. Use -Force to replace an existing app with the same display name.

Sign-in and run mode

Opens a browser sign-in and uses detection.ps1 as the detection rule.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.0'

Checks the folder and files without packaging, signing in, or uploading.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -WhatIf

Deletes any Win32 app with the same display name, then uploads the new one.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.1' `
    -Force

TenantId, ClientId, and ClientSecret are required together.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -TenantId '00000000-0000-0000-0000-000000000000' `
    -ClientId '11111111-1111-1111-1111-111111111111' `
    -ClientSecret $env:INTUNE_CLIENT_SECRET

Detection rules

Without -DetectionRule, Win32Forge uses detection.ps1. Pass one rule or an array of rules.

Runs a PowerShell script on the device. Options default to $false.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -DetectionRule @{
        Type = 'PowerShellScript'
        ScriptPath = 'detection.ps1'
        EnforceSignatureCheck = $false
        RunAs32Bit = $false
    }

Targets the manifest the Contoso sample installer writes.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -DetectionRule @{
        Type = 'FileSystem'
        Path = 'C:\ProgramData\ContosoSampleApp'
        FileOrFolderName = 'manifest.json'
        DetectionType = 'exists'
        Check32BitOn64System = $false
    }

For apps that write a registry value. The Contoso sample does not.

Publish-IntuneWin32App `
    -SourceDirectory ./MyApp `
    -Name 'Contoso Tool' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -DetectionRule @{
        Type = 'Registry'
        KeyPath = 'HKEY_LOCAL_MACHINE\Software\Contoso'
        ValueName = 'Version'
        DetectionType = 'version'
        Operator = 'greaterThanOrEqual'
        DetectionValue = '1.0.0'
    }

For MSI-based apps. Version operator and version are optional.

Publish-IntuneWin32App `
    -SourceDirectory ./MyMsiApp `
    -Name 'Contoso Tool' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -DetectionRule @{
        Type = 'ProductCode'
        ProductCode = '{11111111-1111-1111-1111-111111111111}'
    }

Any hashtable with @odata.type is sent to Graph unchanged.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -DetectionRule @{
        '@odata.type' = '#microsoft.graph.win32LobAppFileSystemDetection'
        path = 'C:\ProgramData\ContosoSampleApp'
        fileOrFolderName = 'manifest.json'
        check32BitOn64System = $false
        detectionType = 'exists'
        operator = 'notConfigured'
        detectionValue = ''
    }

Every rule must match. Combine file, registry, or product code rules; a script rule must stand alone.

Publish-IntuneWin32App `
    -SourceDirectory ./Examples/ContosoSampleApp `
    -Name 'Contoso Sample App' `
    -Publisher 'Contoso' `
    -Version '1.0.0' `
    -DetectionRule @(
        @{
            Type = 'FileSystem'
            Path = 'C:\ProgramData\ContosoSampleApp'
            FileOrFolderName = 'manifest.json'
            DetectionType = 'exists'
        }
        @{
            Type = 'FileSystem'
            Path = 'C:\ProgramData\ContosoSampleApp'
            FileOrFolderName = 'sample-app.txt'
            DetectionType = 'exists'
        }
    )
